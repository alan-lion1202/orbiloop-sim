# Orbiloop 戒指显示效果模拟器

在线预览：**https://alan-lion1202.github.io/orbiloop-sim/**

---

## 老板用法：只想看效果

打开上面的网址即可。或者下载 `index.html` 双击打开（单文件，不用装任何东西）。

---

## 工程师用法：要改代码 / 本地调试

### 1. 下载源文件

点页面右上角绿色 **Code** 按钮 → **Download ZIP**，解压后进入 `src/`。

或者用 git：

```bash
git clone https://github.com/alan-lion1202/orbiloop-sim.git
cd orbiloop-sim/src
```

### 2. 直接打开

双击 `src/戒指3D模拟器.html` 就能运行，**不需要起本地服务器**。

目录结构必须保持原样：

```
src/
├── 戒指3D模拟器.html      ← 改这个文件
├── vendor/three.min.js
└── data/
    ├── shell.js
    └── env.js
```

### 3. 改完怎么发布到线上

回到仓库根目录，执行：

```bash
python3 内联打包.py
```

脚本会把依赖重新内联，生成新的 `index.html`。然后提交推送：

```bash
git add -A && git commit -m "改动说明" && git push
```

约 1 分钟后线上自动更新。

> 注意：`index.html` 是打包产物，**不要直接改它**，改 `src/戒指3D模拟器.html`。

## 模拟器功能

### 显示模式（左侧模式栏切换）

| 模式 | 说明 |
|---|---|
| 开机自检彩蛋 | 开机动画序列，带时间轴和塌缩效果 |
| 电量显示（调试） | 电量数值显示，可拖动电量测试 |
| 低电量文案（调试） | 低电量提示文案 |
| 极低电量文案（调试） | 极低电量遗言 |
| 代码雨 + 文字（主内容） | 主显示内容：数字雨 + 第二幕文字 |
| **蓝牙连接（测试）** | 蓝牙开关动画，2 版本 × 2 状态 |

### 蓝牙动画

**两种开启动画**
- v1 数字雨冲刷：6 列片假名雨从上往下扫，蓝牙符号被逐行冲刷显现
- v2 一笔画：白点沿符号路径走完，符号才完整

**两种状态指示**
- 广播中：符号两侧持续发射信号弧（向外扩散）
- 已连接：符号外围四角对焦框锁定

**熄灭逻辑**
动画播完后符号显示 **3 秒**（可调），然后屏幕熄灭；**蓝牙广播仍在后台继续**，只是不显示。再敲击 6 次可重新点亮 3 秒。

**敲击模拟**
面板里有「敲 1 次」「一键敲 6 次」「清零」，用于模拟加速度计敲击检测。敲满 6 次触发蓝牙开启。

### 3D 视图

- 左键拖动：自由旋转
- 滚轮：缩放
- 双击：复位
- 视角按钮：等轴测 / 俯视（正对屏幕）/ 侧视 / 背面
- 显示比例：实物大小 0% / 2× / 4× / 最近

### 真机标定

- 显示区：**10.89 × 9.29 mm**
- 逻辑分辨率：**150 × 128 px**
- 像素间距：**72.6 µm**
- 外壳形体：21.66 × 26.99 × 19.62 mm（J-001 实测）
- 指孔：Ø19.0 mm（US 9）

## 说明

- 模拟器中的屏幕内容为**效果预览**，不代表固件已验收
- 代码雨时长、字号、列距等参数可在面板中实时调整
- 蓝牙动画中的「3 分钟广播超时」在模拟器中压缩为可调秒数，方便观察
